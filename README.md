# EnRegla

Registros APPCC digitales para bares, restaurantes y pequeños obradores: temperaturas, limpieza, recepción de mercancía, aceite, plagas, formación, incidencias y carta de alérgenos, con informe PDF para la inspección.

Todo el software está en [`enregla/`](enregla/):

- [`enregla/README.md`](enregla/README.md): arranque local, variables y despliegue.
- [`enregla/docs/OPERACIONES.md`](enregla/docs/OPERACIONES.md): despliegue paso a paso, copias de seguridad y Stripe.
- [`enregla/docs/API.md`](enregla/docs/API.md): referencia de la API.

Este repositorio es provisional, hasta que exista el repositorio definitivo del producto.
